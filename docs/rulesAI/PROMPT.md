# Готовая инструкция для coding AI

Перед началом работы полностью прочитай `docs/rulesAI/README.md` и соблюдай его как обязательный стандарт проекта.

Переделай указанную пользователем страницу в визуальном стиле существующих страниц `/platform/*`. Используй общие компоненты из `src/components/platform/PlatformUI.jsx` и `src/components/ui`, а также наиболее похожую готовую страницу из `src/pages/platform` как структурный референс.

Сохрани рабочую бизнес-логику, React Query, API payload, permissions, маршруты, RTL/LTR, английские и ивритские переводы, loading/error/empty состояния и адаптивность. Не используй mock-данные и не дублируй общие UI-компоненты локальным CSS.

Если меняется доступ или состав данных, реализуй проверку и на backend: frontend отвечает за отображение, backend — за реальную защиту. Добавь тесты разрешённых и запрещённых сценариев, затем запусти проверки из раздела «Проверка результата» в `docs/rulesAI/README.md`.
