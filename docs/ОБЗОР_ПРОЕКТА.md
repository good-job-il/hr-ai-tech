# Обзор проекта Hire Israel

Hire Israel — multi-tenant платформа найма с публичным поиском вакансий, candidate кабинетом, employer/agency CRM и platform administration.

## Стек

- Frontend: React 18, Vite, React Router, TanStack Query, Tailwind CSS.
- Backend: NestJS, TypeORM, MySQL, JWT/Passport, Zod.
- Файлы: application-owned local или S3 storage.
- Background work: persisted jobs с idempotency, retry/backoff и scheduler.

## Границы

```text
React pages/components
        ↓
typed domain services + query hooks
        ↓
NestJS controllers/application services
        ↓
TypeORM repositories + MySQL
```

Frontend не определяет tenant identity и не вызывает generic entity/RPC endpoints. Organization scope, permissions, audit events, email и import/AI orchestration принадлежат backend.

Основные точки входа: `src/App.jsx`, `src/api/services/`, `backend/src/app.module.ts`, `backend/src/modules/`.
