# Модули Hire Israel

## Frontend

- `src/pages/` — route-level public, candidate, employer, agency и platform screens.
- `src/components/` — domain UI и layouts.
- `src/api/services/` — типизированные REST domain clients.
- `src/api/hooks/` — React Query orchestration.
- `src/lib/AuthContext.jsx` и `ProtectedRoute.jsx` — session и route boundary.

## Backend

- `auth`, `users`, `organizations`, `permissions` — identity и tenant boundary.
- `jobs`, `candidates`, `applications`, `interviews`, `messages` — core hiring workflow.
- `companies`, `agency-clients`, `agency-teams`, `compensation` — B2B domains.
- `functions` — explicit domain operations, import/AI services и persisted background jobs.
- `integrations` — application-owned file/email infrastructure без generic browser surface.
- `audit`, `communication`, `notifications` — server-authored events.

Каждый новый use case получает явный DTO, controller route, service method, permission/tenant checks и frontend domain-service contract.
