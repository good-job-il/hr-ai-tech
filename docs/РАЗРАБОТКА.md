## Как добавить новую страницу

### 1. Создать файл страницы

```
src/pages/{раздел}/МояСтраница.jsx
```

### 2. Зарегистрировать маршрут в `App.jsx`

Найти нужную группу маршрутов (agency / company / platform и т.д.) и добавить:

```jsx
<Route path="/agency/my-page" element={
  <ProtectedRoute requiredRole={['org_admin', 'recruitment_manager']}>
    <StaffingAgencyLayout>
      <МояСтраница />
    </StaffingAgencyLayout>
  </ProtectedRoute>
} />
```

### 3. Добавить в меню (опционально)

Открыть `src/config/navigation/agencyNav.js` (или нужный файл навигации) и добавить пункт.

## Как работать с данными

### Читать список сущностей

```jsx
import { useQuery } from '@tanstack/react-query';
import { base44 } from '@/api/base44Client';

const { data, isLoading } = useQuery({
  queryKey: ['candidates', filters],
  queryFn: () => base44.entities.Candidate.filter(filters)
});
```

### Создать запись

```jsx
import { useMutation, useQueryClient } from '@tanstack/react-query';

const queryClient = useQueryClient();

const { mutate } = useMutation({
  mutationFn: (data) => base44.entities.CandidateNote.create(data),
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ['candidate-notes'] });
  }
});
```

### Вызвать serverless функцию

```jsx
const result = await base44.functions.scoreApplication.invoke({
  candidateId: '...',
  jobId: '...'
});
```

### Использовать AI-матчинг (клиентский)

```jsx
import { calculateMatchScore } from '@/lib/aiMatching';

const score = calculateMatchScore(candidate, job);
// score: { total: 78, breakdown: { domain: 90, skills: 70, ... } }
```

## Как добавить новую serverless функцию

1. Создать папку `base44/functions/myFunction/`
2. Создать `index.ts`:

```typescript
Deno.serve(async (req) => {
  const { param1, param2 } = await req.json();
  
  // логика
  
  return new Response(JSON.stringify({ result }), {
    headers: { 'Content-Type': 'application/json' }
  });
});
```

3. Вызывать с клиента:

```js
base44.functions.myFunction.invoke({ param1, param2 })
```

## Как добавить новую сущность (entity)

1. Создать файл `base44/entities/MyEntity.jsonc`
2. Описать схему:

```jsonc
{
  "name": "MyEntity",
  "fields": {
    "organization_id": { "type": "string", "required": true },
    "name": { "type": "string", "required": true },
    "created_by": { "type": "string" }
  },
  "rls": {
    "read": "user.organization_id === data.organization_id",
    "create": "user.role !== 'candidate'",
    "update": "user.organization_id === data.organization_id",
    "delete": "user.role === 'org_admin' || user.role === 'admin'"
  }
}
```

## Система разрешений

### Клиентская сторона

Проверка в компонентах через хуки:

```jsx
import { usePermission } from '@/hooks/usePermission';

const canEdit = usePermission('candidate', 'update');
const canDelete = usePermission('candidate', 'delete');
```

Матрица разрешений — `src/lib/permissions.js`.

### Серверная сторона

Для критичных операций — вызов функции:

```js
await base44.functions.checkPermission.invoke({
  action: 'update',
  entity: 'Candidate',
  entityId: '...'
});
```

## Мультиарендная логика

### Получить тип организации в компоненте

```jsx
import { useAuth } from '@/lib/AuthContext';

const { isAgency, isCompany, organization } = useAuth();
```

### Фильтровать данные по организации

Base44 RLS делает это автоматически. Но для явной фильтрации:

```js
base44.entities.Job.filter({
  organization_id: user.organization_id
})
```

## Структура `ProtectedRoute`

```jsx
<ProtectedRoute
  requiredRole={['org_admin', 'hr_manager']}    // один из этих ролей
  requiredOrgType="organization"                 // тип организации (опционально)
>
  <MyPage />
</ProtectedRoute>
```

Super-admin (`admin` / `super_admin`) обходит все проверки.

## Паттерны кодирования

### Импорты с алиасом

```js
import { something } from '@/lib/something';  // = src/lib/something
```

### Форма с валидацией

```jsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';

const schema = z.object({
  name: z.string().min(2),
  email: z.string().email()
});

const { register, handleSubmit, formState: { errors } } = useForm({
  resolver: zodResolver(schema)
});
```

### RTL / Иврит

Все тексты — на иврите. Компоненты должны корректно работать в RTL (`dir="rtl"`).

Классы Tailwind для RTL:
- `text-right` (иврит текст)
- `flex-row-reverse` (если нужно зеркалить flex)
- `rtl:` префикс Tailwind
