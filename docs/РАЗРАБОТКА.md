# Руководство разработчика — Hire Israel

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Frontend направляет `/api` в `VITE_API_PROXY_TARGET`. Backend запускается отдельно из `backend/` после настройки `.env`, базы и миграций.

## Работа с API

Компоненты используют domain services из `src/api/services`, React Query hooks из `src/api/hooks` и ключи из `src/api/queryKeys.ts`. Прямые `fetch`, `axios` и импорт внутреннего HTTP-клиента в UI запрещены.

```jsx
import { useQuery } from "@tanstack/react-query"
import { candidateService } from "@/api/services/candidateService"
import { queryKeys } from "@/api/queryKeys"

const query = { organization_id: organizationId, limit: 50 }
const { data = [] } = useQuery({
  queryKey: queryKeys.candidates.list(query),
  queryFn: () => candidateService.list(query),
})
```

Новые операции добавляются как типизированные методы domain service и явные NestJS endpoint/controller/service. Проверка ролей, tenant scope, audit и side effects выполняется backend.

## Новая страница

1. Создать страницу в подходящем domain-каталоге `src/pages/`.
2. Зарегистрировать маршрут в `src/App.jsx` внутри нужной группы `ProtectedRoute`.
3. При необходимости добавить пункт в `src/config/navigation/`.
4. Добавить query keys, typed service contracts и invalidate rules.
