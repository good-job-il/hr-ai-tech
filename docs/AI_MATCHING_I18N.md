## Использование

### Переключение языка

Пользователь может переключать язык с помощью кнопки `LanguageSwitcher`, расположенной в заголовке страницы (справа от заголовка).

### Кнопка переключения

- **Иврит:** Отображает "English"
- **Английский:** Отображает "עברית"

### Автоматическая адаптация

- **Направление текста:** Автоматически меняется с RTL на LTR и обратно
- **Иконки/стрелки:** Автоматически разворачиваются в зависимости от направления
- **Расположение элементов:** Адаптируется под выбранный язык

## Структура переводов

### aiMatching.page

- `title`: Заголовок страницы
- `subtitle`: Подзаголовок
- `modeCandidateToJobs`: Режим "Кандидат → Работы"
- `modeJobToCandidates`: Режим "Работа → Кандидаты"
- `minScore`: Метка минимального балла
- `all`: Опция "Все"
- `searchCandidate`: Плейсхолдер поиска кандидата
- `searchJob`: Плейсхолдер поиска работы
- `loading`: Текст загрузки
- `selectCandidatePrompt`: Подсказка выбора кандидата
- `selectJobPrompt`: Подсказка выбора работы
- `yearsExperience`: Текст "лет опыта"
- Различные сообщения об успехе/ошибке

### aiMatching.candidatePanel

- `noJobsFound`: Сообщение об отсутствии работ
- `jobsRanked`: Количество ранжированных работ
- `gaps`: Заголовок секции пробелов
- `recommendation`: Заголовок секции рекомендаций
- `assignToJob`: Текст кнопки назначения
- `missingRequirements`: Предупреждение об отсутствующих требованиях

### aiMatching.jobPanel

Аналогично candidatePanel, но для панели работ

### aiMatching.matchBadge

- `aiMatchScore`: Tooltip для значка соответствия

### aiMatching.explanationCard

- `title`: Заголовок карточки объяснения
- `missingRequirements`: Предупреждение о требованиях
- `strengths`: Секция сильных сторон
- `gaps`: Секция пробелов
- `risks`: Секция рисков
- `recommendations`: Секция рекомендаций
- `screeningQuestions`: Секция вопросов для отбора
- `nextAction`: Секция следующего действия

## Тестирование

### Визуальная проверка

1. Откройте страницу AI Matching
2. Переключите язык с помощью кнопки в верхнем правом углу
3. Проверьте:
   - Изменение всех текстов
   - Корректное направление текста (RTL/LTR)
   - Правильное расположение элементов
   - Правильное направление стрелок

### Функциональная проверка

1. Выберите кандидата и проверьте, что панель рекомендаций работ переведена
2. Выберите работу и проверьте, что панель рекомендаций кандидатов переведена
3. Разверните карточку объяснения и проверьте все секции
4. Попробуйте назначить кандидата на работу и проверьте сообщения toast

## Примечания

- Все переводы находятся в структурированном формате
- Используется интерполяция для динамических значений (например, имена кандидатов/работ)
- Компоненты автоматически реагируют на изменение языка благодаря react-i18next
- Направление текста управляется через атрибут `dir` на корневом элементе
